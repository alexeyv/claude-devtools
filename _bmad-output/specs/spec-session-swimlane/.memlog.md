- (direction) Source: in-chat statement of intent for a session swimlane on the existing session view. Not a restyle; turn microscope stays.
- (decision) Slug session-swimlane. Create spec at _bmad-output/specs/spec-session-swimlane/. Rich input: extract directly, no elicitation.
- (note) Why: DevTools is strong inside a turn and weak at interplay. Skill runs (especially BMAD) are orchestrations: parent parks, children run in parallel, HITL is a short gap not the wall.
- (capability) CAP-1 Toggle: user switches a loaded session between the existing turn list and a wall-clock swimlane from session-view chrome. Per-tab, off by default, no Settings.
- (capability) CAP-2 Parent lane: intervals the parent was producing (assistant/tool work) vs silent, on one wall clock from earliest to latest timestamp in parent + resolved children.
- (capability) CAP-3 Child lanes: one lane per spawned Agent/Task child, bar from first to last timestamp in that child jsonl. Parallel children overlap. Nested children are extra rows under their parent, not a second page.
- (capability) CAP-4 HITL marks: ask and answer as marks; gap between them is a wait, not parent work. Inferred from AskUserQuestion, a real user message after parent quiet, or a headless claude -p checkpoint/resume.
- (capability) CAP-5 Profile numbers: each bar shows wall duration plus uncached input, cache read, cache write, output, without opening JSONL. Child bars use that child's own usage, never parent mainSessionImpact.
- (capability) CAP-6 Click-through: parent interval opens that turn in the existing chat view; child bar opens existing subagent detail (expandSubagentTrace). Do not duplicate the microscope.
- (capability) CAP-7 Agent-as-spawn: treat Claude Code Agent tool calls as child spawns, not only Task. Prefer parentTaskId / spawn tool id join; timing fallback (child startTime inside parent chunk) is last resort.
- (constraint) One Claude data root, one session tree. No cross-home stitching (orchestrator in ~/.claude launching claude -p into /tmp/.../claude-home is two roots, out of scope).
- (constraint) Add a projection buildSwimlane(chunks, processes, messages), not a second session model. Use SessionParser, SubagentLocator/SubagentResolver, ProcessLinker, and Process (startTime, endTime, parentTaskId, metrics).
- (constraint) Do not edit ChunkBuilder except as required to classify Agent as a spawn. Do not restyle ChatHistory. Do not add a new parser or a third interpretation of unofficial jsonl; inherit existing drift handling.
- (constraint) Child file paths go through the existing locator. Do not hardcode projects/<id>/subagents/ vs projects/<id>/<sessionId>/subagents/.
- (constraint) A silent stretch must never look like work. Wrong wait-class is acceptable if the gap is still drawn.
- (constraint) Isolate: (1) pure lane-model function testable without Electron; (2) small view reusing existing surface colors and type, no new design system; (3) one button, tab-local toggle like Context panel, off by default; (4) click-through calls existing navigation.
- (constraint) HITL is inferred, not a log type. Label the mark; do not pretend certainty. Headless checkpoint = last assistant in a segment, then a later user string that is not a tool_result and not isMeta.
- (decision) Default remains the turn list. Swimlane is opt-in, per tab, no settings, no theme work.
